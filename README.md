# SMS Spam Classifier

A Machine Learning and NLP based web application that detects whether a message is Spam or Not Spam.

## Live Demo
Add your Streamlit app link here

## Features
- Spam message detection
- NLP text preprocessing
- TF-IDF Vectorization
- Multinomial Naive Bayes model
- Streamlit web interface

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- NLTK
- Pandas
- NumPy
